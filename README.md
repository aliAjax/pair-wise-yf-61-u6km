# 远程设备固件分批发布控制台

源提示词摘要：发布负责人选择设备范围、固件版本、分批比例和回滚版本，运维设定兼容条件与失败阈值，值班人员监视下载、安装、重启和异常事件；关键发布支持审批、暂停、继续和紧急回滚，过期状态不可误用。

## 技术栈

Angular、TypeScript、Angular Material、NgRx、Angular Router、RxJS、Angular CDK、Transloco。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62026`

## 发布账（release ledger）

设备分组、发布批次与设备回执三方记账，核心规则由纯函数实现（`src/app/ledger/ledger.ts`），不依赖 UI：

- **每台设备一行流水**：回执只追加，按回执号幂等，重复回执永远只算一次；pending 回执被最终结论回执“替代”（占位顺延，不重复计数）。
- **分组占位与容量**：每个分组按灰度比例给出容量，占位 = 当前版本有效回执数，超出容量的回执拒收。
- **版本变化（换版发布）**：旧版本未执行（pending）回执标记 stale 并立即释放分组占位；旧版本已安装/失败设备保留现场（统计中显示为“旧版保留现场”），迟到的旧版本回执一律拒收，不能继续推进已暂停或回滚的批次。
- **双人并发**：批次带乐观锁 `revision`，两个值班员同时提交同一批回执时，后到者收到冲突结果——冲突设备清单、最新 revision、最新版本与状态，并可带最新账期重试（自动跳过冲突设备）。
- **部分失败重试**：按分组写入失败时已完成分组保留，只重试失败分组；整批重发也安全，成功分组的同号回执命中幂等，不会重复计数。
- **回滚保护**：回滚后所有回执拒收，已安装现场保留，任何重试都不能覆盖回滚。

## 验证

```bash
npm run test:ledger   # 8 项发布账纯逻辑断言（幂等/占位/换版/冲突/部分重试/回滚等）
npm run build
```

## 可用流程

- 创建发布批次并关联多个设备分组、固件版本、分批比例和失败阈值。
- 批次从草稿、已审批、发布中、暂停到完成或回滚；暂停/回滚后晚到回执只登记现场或被拒收，不推进状态。
- 界面可手工提交回执、模拟双人同批并发、模拟分组写入失败并重试、注入晚到回执、执行版本变更。
- 兼容条件阻止不合格分组加入发布；审计记录与发布账持久化到 localStorage（`firmware-release-ledger-v2`）。
